# 数据、权限与原生进程说明

## 权限与数据

- 唯一 Manifest 权限为 `host.storage`。只调用本插件命名空间的 `get/set`，保存键为 `maledb.session.v1`。
- 保存内容为昵称、声音/提示/出牌速度偏好、当前牌局、各座位游戏分数、最近 30 局结果，以及防止重复结算的牌局标识。
- 不读取数据库连接、数据库内容、凭据、宿主文件、剪贴板或其他插件数据。不需要数据库连接即可打开工作台。
- 预览模式使用该本机站点的 `localStorage`，与 DBX 内的存档分开。
- 没有遥测、分析 SDK、账号系统、远程登录、云端存档或后台上传。牌分没有充值、兑换或现金价值。

## 网络和原生行为

- DBX 启动随包提供的 Go/C++ 原生 Sidecar，通过 stdin/stdout JSONL RPC 接收 `mahjong/score`，返回番型和计分。请求大小与牌串长度有上限，非法参数会被拒绝。
- 正常插件运行不打开网络监听、不访问互联网、不读写用户文件、不执行 shell 或其他子进程、不下载更新。
- 原生 Sidecar 具有当前用户的操作系统权限；Manifest 权限仅限制宿主接口，不构成原生进程的操作系统沙箱。
- 只有显式使用 `--preview 127.0.0.1:<端口>` 启动开发预览时，才提供本机 HTTP 页面和算番 API。预览拒绝非回环监听地址，并校验 HTTP Host 与 Origin；发布入口不会自动启动 HTTP。
- 全部图片、JS、CSS、SVG 随包离线提供；音效由 Web Audio 本地合成，不使用远程音频或 CDN。

## 许可和规则

- 原创代码采用 Apache-2.0；第三方算番核心采用 MIT；官方 DBX Go SDK 采用其 Apache-2.0 许可，完整通知随包提供。
- 主视觉由 imagegen 生成，所用提示词在 `designs/`；真实控件与文字由代码实现。
- 本地一人加三位电脑，采用 README 中明确列出的固定大众基础桌。未逐项复刻欢乐麻将所有房间，不提供在线或局域网多人。
- 当前公开候选只包含 `darwin-arm64`。界面为简体中文，商店简介提供中英文。
- 验证范围及尚未执行的实际桌面 WebView 联调见 `VALIDATION.md`。
