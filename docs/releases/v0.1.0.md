# 麻了DB v0.1.0

写麻了？摸两张。

- 疲惫红中首页、青瓷牌桌、正常昵称与头像的三位电脑牌友。
- 四人单机麻将，支持补花、吃、碰、明杠、暗杠、补杠、抢杠胡、接炮与自摸。
- 原生番型与互斥计分，结算展示明细，牌分零和且不会重复结算。
- 支持鼠标与键盘出牌、提示、托管、暂停、音效开关、昵称及出牌速度设置、本地续局和最近 30 局结果。
- DBX 元素保留在牌背与工作台细节，不额外增加行牌规则。

当前平台为 **macOS Apple Silicon / darwin-arm64**，需要 DBX 0.6.36+。这是供 DBX Store 审核的未签名候选；审核签名后才会成为商店安装包。本地安装需显式允许未签名开发包。

仅使用 `host.storage` 保存本地游戏数据。正常运行不联网、不读取数据库或凭据，原生进程只负责本地算番。固定规则、隐私和验证范围见 README、`docs/security.md` 与 `VALIDATION.md`。

已通过 9 项测试、130 组番型/互斥样例、100 局电脑对战、真实 DBX SDK/CSP 沙盒交互和独立安装器校验。实际桌面 WebView 安装联调仍待验证。

English: Initial MaLeDB store candidate for macOS Apple Silicon. Four-player offline Chinese Mahjong with three bots, native fan scoring, flowers, chi/peng/kong/hu, hints, auto-play, sounds and saved games. Only `host.storage` is requested. Native code runs with user OS privileges but performs only local scoring in plugin mode. The exact room rules and current verification limits are documented in the source repository.
